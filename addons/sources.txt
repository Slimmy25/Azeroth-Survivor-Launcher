# Where each addon copy on the "addons" release comes from. One addon per line:
#   file name on the release | original download link
# The "Mirror addons" workflow downloads every link below, checks it is a real .zip and puts it on the
# "addons" release under that file name (replacing the old copy). It runs by itself when this file changes,
# or by hand: Actions > Mirror addons > Run workflow (do that to pick up a new version of an addon).
# "local:<folder>" instead of a link zips that folder of this repository (addons/<folder>) instead;
# "hosted" means the zip lives on the "addons" release itself (uploaded there by hand: to update it, upload the new
# zip under the same name on the release); the workflow only checks that it is there.
# "github-latest:<owner>/<repo>" takes the .zip of that repository's newest release (its name can change);
# "github-latest:<owner>/<repo>:<prefix>" only a .zip whose name starts with <prefix> (a release with other zips too).
# "local:<folder>+<folder>" zips several folders into the one .zip (an addon that comes with a second one).
# The launcher's Download More list (assets/addons.txt) points at:
#   https://github.com/Slimmy25/Azeroth-Survivor-Launcher-Releases/releases/download/addons/<file name>
