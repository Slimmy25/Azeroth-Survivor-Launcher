# Project-Launch testing branch

This branch is isolated from main. It is reserved for reviewing the unified Build Planner prototype and ASB2 interoperability work.

Status: experimental; no executable integration, compilation or website round-trip validation has been completed. Do not release as production.

Planned behavior: one class selection; Talents/Gear tabs; shared named persistent builds; import/export with a compatibility adapter. Preserve the existing WoW-era visual theme and legacy talent codes.

ASB2 caveat: gear and stars are local-only; third-party talent transfer is not confirmed.

Existing draft source packages were prepared separately in the ChatGPT conversation. They require integration and testing before being treated as working launcher features.
