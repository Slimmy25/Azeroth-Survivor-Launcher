## In short

Talent builds load as soon as you select a saved name, and share codes now have a validated, versioned format for reliable importing between players. The test executable is removed; this is the sole launcher release.

## Talent Tree Builder
- Selecting a saved build name immediately loads that build.
- EXPORT creates a compact share code containing the format version, class and talent allocations.
- IMPORT validates the code and explains class mismatches or invalid talent allocations. Older unversioned codes are accepted where possible.

## Release
- Removed the separate test executable from local builds, CI artifacts and published releases.
