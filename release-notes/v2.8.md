# v2.8 (2026-10-29)

## Add-ons

- Survivor UI and SurvivorUI Classic are delivered as one Download More bundle. They are enabled and disabled together, while the in-game chooser selects which interface is active.
- The add-on mirror combines the latest matching ZIP from each creator repository and checks archive paths before extraction.

## Setup and launcher behavior

- The first-time setup language page keeps its Next button visible.
- Skipping cloud saving no longer leaves a blocking message over the launcher. If cloud saving remains enabled, setup explains inline that a sync folder must be selected.
- Closing the launcher exits by default. Hiding it in the Windows tray is an opt-in setting under Options > Launcher.
- Quick Access help text is cleared when first-time setup starts, favorite dragging shows its drop target, and class-page favorites use class icons while class gear pages use their selected helmet art.
- Lost? help is shown inside the secondary menu with separate link-tree and favorite examples.
