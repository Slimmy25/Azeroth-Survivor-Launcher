# Azeroth Survivors Launcher v3.0

## First-time setup

- Setup now has a six-step flow with a visible breadcrumb, one-slide Back, Start Over, and Cancel Setup controls.
- Choices remain pending until the final step. Canceling first-time setup cleans up launcher data and temporary downloads without touching the game, saves, or cloud files.
- The final step offers **READY TO DOWNLOAD AND PLAY?** to start installing the game into the selected folder. If the game is already there, **FINISH SETUP** completes the flow without downloading it again.
- Launcher navigation and Quick Access are unavailable during setup and return when setup finishes.

## Quick Access

- Guide categories that contain child pages can also be saved from their Guide cards and search results.
