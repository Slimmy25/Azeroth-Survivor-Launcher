# Azeroth Survivors Launcher v3.01

## Setup cancellation

- Canceling first-time setup removes only launcher settings, sync state, logs, and the uniquely named temporary game download.
- Existing player files—including game saves, AddOns, addon settings, cloud files, addon profiles, backups, and saved launcher content—are preserved.

## Hover behavior and Quick Access

- Hover cards and themed tooltips close when the launcher loses focus and stay hidden while it is inactive or minimized.
- The Quick Access heart now centers over the rendered breadcrumb text, excluding menu arrows and layout padding.
