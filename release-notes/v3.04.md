# Azeroth Survivors Launcher v3.04

## Guide search

- Guide links now take you to the matching passage on the page.
- Search remains available while browsing results, so you can continue searching from the current page.
- Spell results include related Codex entries and matching set bonuses; the Codex includes Lightwell and Rend.

## Saves and updates

- Added an option to export a validated save file for another client or the browser game.
- Launcher updates are offered inside Options > Launcher, where you can install the update or choose later.
